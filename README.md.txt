# 🔥 Forest Fire Prediction

A machine learning web application that predicts forest fire conditions using environmental data.

## 🚀 Live Demo

👉 [Try the Forest Fire Prediction App](https://forest-fire-prediction-j3e7.onrender.com)

## 🛠️ Technologies Used

- Python
- Flask
- NumPy
- Pandas
- Scikit-learn
- HTML
- CSS
- Ridge Regression

## 📌 Project

This project uses a trained machine learning model to predict forest fire conditions based on environmental parameters.
